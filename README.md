# Elsewhere

Clickable prototype for Elsewhere, a CS147 project for turning free time into small outings nearby.

**Live:** https://romina-jately.github.io/elsewhere-prototype/

The whole prototype is `index.html`: one self-contained file with images and icons embedded. Fonts load from Google Fonts.

## Flows
- Login and onboarding (interests, friends)
- Home and Discover, with the place detail card
- Planning a visit solo, or a spontaneous hangout matched within a circle
- Budget overview and editing
- Circles: friends, editing circles, and messages
- Profile: your map of places visited, interests, calendar, and settings

On desktop, the left rail jumps to any screen and resets the prototype.
